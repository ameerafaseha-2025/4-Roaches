# LIPAS: From Longkang to Luxury

A 3D browser game built with Vite, React, TypeScript, Three.js, React Three Fiber and Zustand. All art and audio are generated in code.

## Run

```sh
npm install
npm run dev
```

Build with `npm run build`.

## Story

A cockroach finds his mate and builds a family. A human ruins their life, so the father invades the house. Six rooms, a boss domain (Mak with her slipper, the Janitor with the spray), then the luxury food on the second floor.

## Controls

| Input | Action |
| --- | --- |
| Space | Take off / land |
| W / S | Pitch nose up / down (walk forward / back on the ground) |
| A / D | Bank and turn |
| E | Climb boost |
| Shift | Sprint (uses stamina) |
| C | Land immediately |
| Esc | Pause |

Touch screens get a virtual stick plus Fly, Sprint and Boost buttons.

## Rules

- Fly into a human's face to stick to it. Each stick fills their fear bar. Fear drains again if you leave them alone.
- Fill every fear bar to 100 to open the door, then fly through it.
- Flying drains energy. Eat scraps to refill it. Sprinting drains stamina.
- Bosses throw slippers and spray, so they are harder to land on.
